## Known gaps

- **Small sample.** 6 unanswerable questions in the tuning split: one abstention moves the abstention rate by about 17 points. Read the intervals, not the point estimates.
- **Public golden set.** Future models may train on it; the closed-book baseline (L13) is the guard, and it is still pending.
- **No faithfulness metric** (decision 18). The judge measures agreement with the reference answer; citation validity checks only that each citation points at a retrieved chunk.
- **Answer correctness pending** (decision 19). The judge's free-tier quota (20 requests per model) stopped the run; `eval judge --resume` completes it with the same judge.
- **Uncalibrated judge** (decision 19). No judge-human agreement has been measured yet.
- **Closed-book baseline not run** (decision 19): the Anthropic API rejected the run (`organization_on_hold`). RAG gain is pending.
- **Incident answers not scored** (decision 19): incident results are retrieval only.
- **SCN-07 hint** (decision 11). Its situation text hints at its cause, so its retrieval score is likely optimistic.
- **Format heuristic.** The `multi_sentence` abstention check counts sentence-ending punctuation and can over-count abbreviations.
- **Dev-query overlap.** One dev query has a max cosine of 0.73 to a tuning question. Dev queries were not used for any tuning, so this is recorded, not corrected.
